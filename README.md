# Geographic Duel — Flutter / Светлый атлас

Перенос утверждённого дизайна на Flutter. Это Flutter-виджеты, а не WebView и не HTML-обёртка. Главный файл — `lib/main.dart`.

## Что включено

- Главная с исходным векторным глобусом, хвойной кнопкой и стеклянной навигацией.
- Поиск демонстрационного соперника и отмена поиска.
- Раунд с локальной фотографией, таймером 60 секунд, здоровьем и просмотром разных частей фотографии.
- Нижняя шторка с обзорной картой мира: перемещение, масштабирование, выбор касанием и ввод координат.
- Сохранение черновика точки при закрытии карты, блокировка подтверждения без точки, ожидание и результат.
- Истечение срока даёт 0 очков, даже если на карте был неподтверждённый черновик.
- Рейтинг, профиль, уменьшение прозрачности и движения.
- Локальные ресурсы: после сборки демонстрации интернет не нужен.

Фотография, соперник, рейтинг и профиль демонстрационные. Проигрывается один повторяемый раунд. Это перенос UI; авторизация, Firebase и онлайн-дуэль пока не подключены. Значение «5 раундов» на главной отражает дизайн будущего режима. Правильная координата в коде допустима только для этого демо.

## Запуск

Нужны установленный Flutter stable и соответствующие инструменты платформы. Откройте терминал в этой папке:

```sh
flutter pub get
flutter run -d chrome
```

Для мобильных платформ сначала создайте стандартные Android/iOS-файлы:

```sh
flutter create --project-name geographic_duel --platforms=android,ios .
flutter pub get
flutter run
```

Команда `flutter create` без `--overwrite` сохраняет существующие исходники. Android требует Android SDK/эмулятор или устройство. Сборка iOS выполняется на macOS с Xcode. Серверные ключи не требуются.

Для переноса в существующее Flutter-приложение скопируйте папки `lib` и `assets`, а также перенесите зависимость `flutter_svg`, секции assets и fonts из `pubspec.yaml`. Точка входа — `GeographicDuelApp`.

## Структура

```text
lib/main.dart          экраны, стеклянные компоненты, состояние интерфейса
lib/atlas_map.dart     локальная карта, проекция, жесты, маркеры
lib/duel_logic.dart    демонстрационные расстояния, очки, урон
assets/               глобус, карта, фотография, шрифт и его лицензия
test/                 проверки расчётов и основных переходов
web/index.html        запуск Flutter в браузере
```

В дальнейшем `_search`, `_startRound` и ожидание результата заменяются событиями `MatchRepository`. Расстояние, здоровье и рейтинг для онлайн-игры должны рассчитываться сервером. Интерфейс `RoundResult` служит моделью представления результата.

## Проверка

```sh
flutter analyze
flutter test
flutter build web
```

Фактический статус проверки указан в `VALIDATION.md`. Flutter-стекло реализовано через `BackdropFilter`, градиент и светлый край. Это собственный визуальный эффект; поведение нативного Apple Liquid Glass не обещается. Настройки прототипа сохраняются до закрытия приложения. Карта обзорная, без дорожных тайлов; маршруты в результате служат визуальными соединениями, расстояние рассчитывается haversine.

## Ресурсы

- Геометрия: Natural Earth через [World Atlas 2](https://github.com/topojson/world-atlas), проекция d3-geo. Геометрия общественного достояния; генератор World Atlas — ISC.
- Глобус: векторный ресурс из утверждённого макета, построен по той же геометрии.
- Шрифт Lora: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/lora), SIL Open Font License; текст лицензии включён в `assets/Lora-OFL.txt`.
- Фото: [A-Frame panorama example](https://github.com/aframevr/aframe/tree/v1.7.1/examples/boilerplate/panorama). Оставлено для соответствия демонстрационному макету; права на исходную фотографию нужно отдельно подтвердить перед публикацией или заменить её собственным ресурсом.
- Опорная точка Пюи-де-Санси: 45.52824 N / 2.81401 E. Не является подтверждённой точкой съёмки фотографии.

Дизайн принят пользователем 30 сентября 2026 года. Мобильный шрифт Lora с кириллицей включён вместо зависящей от системы Georgia; на всех платформах используется одинаковый ресурс.
